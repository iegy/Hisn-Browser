# HISN starter domain rules

This file describes the small, bundled starter domain list used by HISN's request blocker. The list is intentionally conservative and is not copied from a third-party filter-list repository. It is a seed list, not a full EasyList/EasyPrivacy implementation. A domain may serve both essential and tracking content, so per-site allowlisting is available.

No filter list is fetched on every page load. There is currently no automatic remote filter-list update. Block counts represent requests intercepted by HISN, not all ads removed from a page.
